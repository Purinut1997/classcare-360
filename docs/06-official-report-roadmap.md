# โครงสร้างระบบรายงานเอกสารราชการ

## มาตรฐานที่ใช้งานในรอบปัจจุบัน

- เอกสารพิมพ์ใช้กระดาษ A4 แนวตั้งหรือแนวนอนตามชนิดข้อมูล และใช้แบบอักษร TH Sarabun New
- ส่วนหัวระบุชื่อหน่วยงาน ชื่อรายงาน ปีการศึกษา ภาคเรียน เลขที่เอกสาร และวันที่ออกรายงาน
- ตารางใช้สีขาวดำ มีข้อความรับรองความถูกต้อง ผู้ลงนาม 3 ลำดับ และส่วนท้ายกำกับชั้นความลับ
- วันที่ในเอกสารแสดงตามรูปแบบภาษาไทยและปีพุทธศักราช
- เลขประจำตัวประชาชนถูกปกปิดโดยค่าเริ่มต้น และเปิดเผยได้เฉพาะเมื่อผู้ใช้เลือกก่อนพิมพ์
- ครอบคลุมรายงานเวลาเรียนรายวัน/รายวิชา เงินออม คะแนน สุขภาพ พฤติกรรม รายบุคคล ทะเบียนนักเรียน สรุปผู้บริหาร ตารางสอน ปฏิทินโรงเรียน ตารางเวร และแบบเยี่ยมบ้าน

## โครงสร้างที่ควรพัฒนารอบถัดไป

### 1. ทะเบียนเลขที่เอกสารกลาง

- เพิ่มตาราง `official_documents` สำหรับเลขที่เอกสาร ปีการศึกษา รุ่นเอกสาร สถานะ และค่า hash ของไฟล์
- ออกเลขที่เอกสารจากฐานข้อมูลแบบ atomic แยกตามประเภทเอกสารและปีการศึกษา
- ห้ามแก้เนื้อหาเอกสารที่อนุมัติแล้ว ให้สร้างฉบับแก้ไขและเชื่อมโยงกับฉบับเดิม

### 2. กระบวนการเสนอ ตรวจ และอนุมัติ

- สถานะมาตรฐาน: `draft` -> `submitted` -> `reviewed` -> `approved` -> `archived`
- เพิ่มผู้รับผิดชอบ ผู้ตรวจสอบ ผู้อนุมัติ วันที่ดำเนินการ และหมายเหตุส่งกลับแก้ไข
- เก็บเหตุการณ์ทุกขั้นใน audit log และจำกัดสิทธิ์ตามบทบาทของสถานศึกษา

### 3. PDF ต้นฉบับและการตรวจสอบย้อนกลับ

- สร้าง PDF ฝั่งเซิร์ฟเวอร์หลังอนุมัติ เก็บใน private storage ตาม `workspace_id`
- ฝัง QR code หรือรหัสตรวจสอบที่หน้า public lookup โดยไม่เปิดเผยข้อมูลส่วนบุคคล
- เก็บ checksum, เวลาสร้าง, ผู้สร้าง, เวอร์ชันแม่แบบ และวันหมดอายุของลิงก์ดาวน์โหลด

### 4. คลังแม่แบบเอกสาร

- แยกแม่แบบตามประเภทเอกสาร พร้อมเลขเวอร์ชัน วันที่เริ่มใช้ และผู้อนุมัติแม่แบบ
- รองรับตราโรงเรียน ตราส่วนราชการ ที่อยู่ หนังสืออ้างอิง และรายชื่อผู้ลงนามตามช่วงเวลา
- เพิ่มการทดสอบภาพเทียบแม่แบบ A4 เพื่อป้องกันตารางล้นหน้าและลายเซ็นหลุดหน้า

### 5. รายงานสรุปผู้บริหารฉบับวิเคราะห์

- บันทึกค่าเป้าหมายรายตัวชี้วัดแยกตามปีการศึกษาและระดับชั้น
- เพิ่มแนวโน้มเทียบเดือน/ภาคเรียน/ปีก่อน รายชื่อนักเรียนที่ต้องติดตาม และผู้รับผิดชอบแผนแก้ไข
- เพิ่มภาคผนวกแหล่งข้อมูลและเวลาปรับปรุงล่าสุด เพื่อให้ผู้บริหารตรวจสอบที่มาของตัวเลขได้

### 6. ความมั่นคงปลอดภัยและการคุ้มครองข้อมูล

- บันทึกเหตุการณ์พิมพ์ ดาวน์โหลด เปิดเผยเลขประจำตัว และตรวจสอบเอกสาร
- เพิ่มเหตุผลการเปิดเผยข้อมูลอ่อนไหวและ session timeout สำหรับหน้ารายงานลับ
- กำหนดระยะเวลาเก็บรักษา การทำลายเอกสาร และการส่งออกตามนโยบายของสถานศึกษา

## ลำดับแนะนำสำหรับรอบถัดไป

1. ทำทะเบียนเลขที่เอกสารกลางและ workflow อนุมัติให้เสร็จก่อน
2. สร้าง PDF หลังอนุมัติพร้อม private storage และ audit log
3. เพิ่ม QR ตรวจสอบเอกสารและหน้า public lookup แบบไม่เปิดเผยข้อมูลส่วนบุคคล
4. ทำคลังแม่แบบและ visual regression สำหรับ A4
5. ขยายรายงานผู้บริหารด้วยเป้าหมาย แนวโน้ม และแผนติดตาม
