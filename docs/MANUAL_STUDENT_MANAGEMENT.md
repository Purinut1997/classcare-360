# คู่มือการจัดการและลบรายชื่อนักเรียน (Student Management & Deletion Guide)
**ClassCare 360**

---

## 1. ความแตกต่างระหว่าง "ลบถาวร" vs "เก็บถาวร"

| การทำงาน | จุดประสงค์ | ผลกระทบต่อข้อมูล | เมนูที่พบ |
| :--- | :--- | :--- | :--- |
| 🗑️ **ลบถาวร (Delete Permanently)** | ใช้สำหรับ **ข้อมูลผิดพลาด**, **นำเข้าผิดไฟล์**, **ข้อมูลซ้ำซ้อน** หรือรายชื่อทดสอบที่ต้องการทำลายทิ้ง | ลบข้อมูลออกจากฐานข้อมูลจริงอย่างสมบูรณ์ (โดยระบบจะสำรองเข้าถังขยะ `trash_items` 90 วันเพื่อความปลอดภัย) | หน้านำเข้า/สำรอง (Import/Export), หน้ารายชื่อนักเรียน |
| 📦 **เก็บถาวร (Archive)** | ใช้สำหรับนักเรียนที่ **ย้ายโรงเรียน**, **พักการเรียน**, หรือ **จบการศึกษา** | ข้อมูลยังคงอยู่ในระบบเพื่อดูประวัติเกรดและเวลาเรียนย้อนหลังได้ แต่จะไม่ถูกนับในแดชบอร์ดปัจจุบัน และไม่แสดงในห้องเรียนปกติ | หน้ารายชื่อนักเรียน, การจัดห้องเรียน |

## 2. วิธีการลบรายชื่อนักเรียนถาวร (ลบได้ทันที ไม่ต้องเก็บถาวรก่อน)

ระบบได้รับการอัปเดตแล้ว **สามารถลบนักเรียนที่มีสถานะปกติ (กำลังเรียน) ได้ทันที** โดยไม่ต้องกด "เก็บถาวร" ก่อนอีกต่อไป!

### วิธีที่ 1: ลบเป็นกลุ่มจากหน้านำเข้า/สำรอง (Import / Export)
1. ไปที่เมนู **"นำเข้า/สำรอง"** ด้านซ้าย
2. เลื่อนลงมาที่ส่วน **"จัดการรายชื่อที่นำเข้าแล้ว"**
3. เลือกตัวกรอง (เช่น ดูทั้งหมด, ข้อมูลซ้ำ, หรือยังไม่ผูกห้อง)
4. ติ๊กเครื่องหมายถูกหน้า **"เลือก"** (สามารถกดเลือกทั้งหมดในหน้านั้นได้)
5. กดปุ่มสีแดง **"ลบถาวร"** ที่มุมบนขวาของตาราง
6. กดยืนยันในกล่องข้อความเตือน ระบบจะทำการลบข้อมูลนักเรียนและประวัติที่เกี่ยวข้องออกจากฐานข้อมูลทันที

### วิธีที่ 2: ลบทีละคนจากหน้ารายชื่อนักเรียน (Students Page)
1. ไปที่เมนู **"รายชื่อนักเรียน"**
2. เลือกแท็บ **"ตรวจสอบคุณภาพข้อมูล"** หรือตัวกรองรายชื่อ
3. ค้นหารายชื่อที่ต้องการลบ
4. กดปุ่มสีแดง **"ลบถาวร"** ของรายชื่อนั้น
5. กดยืนยัน ระบบจะทำการลบนักเรียนคนนั้นออกจากระบบทันที

---

## 3. วิธีการกู้คืนรายชื่อ (หากเปลี่ยนใจหลังจากกดเก็บถาวร)

หากกด "เก็บถาวร" ไปแล้วต้องการนำนักเรียนกลับมาเข้าเรียนปกติ:
1. ไปที่หน้า **"นำเข้า/สำรอง"** หรือ **"รายชื่อนักเรียน"**
2. เลือกหมวด **"หมวดเก็บถาวร"**
3. ติ๊กเลือกรายชื่อที่ต้องการ
4. กดปุ่ม **"กู้คืน"** (Restore)
5. นักเรียนจะกลับมาเป็นสถานะปกติ (Active) และสามารถกำหนดห้องเรียนได้ทันที
